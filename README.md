# Pi 4 Offline Computer

A raspberry Pi 4 project designed to provide useful resources even without internet 

## Goals
-Offline Wikipedia using Kiwix
-Offline Maps
-Automatic temperature-based fan control
-Physical button for safe shutdown and startup
-CPU temperature monitoring

## Hardware

-Raspberry 4
-microSD card
-Cooling Fan
-Power Button
